# 🎰 Gamble Klicker

Ein Browser-Spiel, das **Cookie Clicker** mit einem **Casino** verbindet:
Klicke auf die Münze, kaufe Gebäude für passives Einkommen und setze dein
Spielgeld später bei Slots, Roulette, Blackjack und Poker ein.

> Alles ist **reines Spielgeld** ohne echten Wert. Es gibt keine Käufe mit echtem Geld.

## Spielen

Einfach `index.html` im Browser öffnen – keine Installation nötig.
Der Spielstand wird automatisch im Browser gespeichert.
